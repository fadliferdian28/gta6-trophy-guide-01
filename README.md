A complete offline trophy guide and progress tracker for GTA VI on PS5. Every one of the 55 official trophies ships with a cited, step-by-step walkthrough, plus a roadmap that orders the platinum run and flags which trophies can be permanently missed. Where sources disagree the guide shows both readings instead of silently picking one, and your checklist is saved in the browser so a session never loses its place.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080 in your browser.
